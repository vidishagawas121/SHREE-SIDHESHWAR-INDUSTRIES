# Shree Sidheshwar Industries - Official Website

A production-ready, responsive, industrial-grade static website for **Shree Sidheshwar Industries** (Bhosari, Pune).

Specialized in:
- CNC Machining & Turning
- Precision Honing
- Hard Chrome Plating
- Machining Facility
- Manufacturing & Refurbishment of Hydraulic Cylinders

## 🛠️ Tech Stack

- **Framework**: React 18
- **Bundler / Tooling**: Vite 5
- **Icons**: Lucide React
- **Typography**: Google Fonts (Outfit & Inter)
- **Styling**: High-performance Vanilla CSS with dark industrial aesthetic, gold accents, and zero runtime overhead
- **Architecture**: Frontend-only (No Express, No MongoDB, No Backend, No Auth)
- **Deployment**: Vercel ready (`vercel.json` included)

---

## 🚀 Getting Started Locally

### Prerequisites
- Node.js (v18 or higher)
- npm

### 1. Installation
```bash
npm install
```

### 2. Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Production Build
```bash
npm run build
```
Creates an optimized production bundle in `/dist`.

### 4. Preview Production Build
```bash
npm run preview
```

---

## 🌐 Deploying to Vercel

1. Push this repository to GitHub or GitLab.
2. In the [Vercel Dashboard](https://vercel.com):
   - Click **Add New Project**
   - Import your repository
   - Framework Preset: **Vite**
   - Root Directory: `./`
   - Build Command: `npm run build`
   - Output Directory: `dist`
3. Click **Deploy**.

The project includes `vercel.json` with single-page rewrite rules configured.
